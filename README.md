## 📌 About The Project

**KnowBridge AI** is an AI-powered knowledge management platform designed to help teams organize, manage, connect, and share organizational knowledge in one centralized workspace.

It aims to reduce knowledge gaps, improve collaboration, simplify information sharing, and make important decisions and project knowledge accessible to team members.

The platform provides a structured workspace where users can manage knowledge sources, projects, tasks, decisions, and team handovers.

## ✨ Key Features

- **Dashboard:** Centralized workspace to access important information.
- **Knowledge Sources:** Organize and manage knowledge resources.
- **Project Management:** Manage projects and related information.
- **Task Management:** Track and organize tasks.
- **Decision Management:** Maintain important project decisions.
- **Smart Handover:** Simplify knowledge transfer between team members.
- **Workspace Management:** Manage workspace settings and summaries.
- **User Authentication UI:** Login, signup, and verification interfaces.
- **User Profile:** Dedicated profile management interface.

## ⚙️ Installation and Setup

Follow these steps to run KnowBridge AI locally.

### 1. Clone the Repository

```bash
git clone https://github.com/Sumit-pandey30/KnowBridge-AI.git
```

### 2. Navigate to the Project Directory

```bash
cd KnowBridge-AI
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

### 5. Open in Browser

```text
http://localhost:5173/
```

## 🏗️ Build for Production

To generate an optimized production build:

```bash
npm run build
```

To preview the production build locally:

```bash
npm run preview
```
